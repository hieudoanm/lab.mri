Explore real brain MRI data, run computational neuroscience experiments, and share reproducible results — all in the cloud.

MRI Lab is a cloud workbench for NIfTI volumes: a precise multiplanar viewer, versioned processing pipelines, and machine-readable experiment manifests. No server to configure, no data wrangling to reproduce.

Capabilities

A viewer and a lab on the same project and artifact system

Display transforms are never recorded as analytical inputs. The volume is the primary content; everything else recedes.

View

Linked axial, coronal, and sagittal planes with a shared crosshair, window/level, colour maps, and atlas or mask overlays registered through the volume affine.

  • Voxel and world coordinate readout with explicit coordinate space
  • Region inspection tagged with atlas name and space
  • Colour-blind-safe maps by default

Compute

Run versioned pipelines in isolated containers — Gaussian smoothing, skull stripping, resampling — with explicit resource limits and honest status feedback.

  • Immutable pipeline versions pinned by image digest
  • Parameters rendered from a typed schema with units
  • Streamed logs that never leak credentials or raw voxels

Share

Every completed run produces a machine-readable manifest with input checksums, parameters, environment, and outputs — so a collaborator can reproduce it, not just read about it.

  • Copyable provenance and SHA-256 checksums
  • Scoped sharing links with expiry and revoke
  • Public sample projects with visible licence and citation
